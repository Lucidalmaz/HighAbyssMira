Legende „im Code gefunden?“: **ja** = sichtbares Mesh/Dekal vorhanden (hier nicht aufgeführt) · **nur Hitbox** = nur unsichtbare Klickfläche (`hidden`-Material) · **nein** = nichts gebaut · **teilweise** · **Widerspruch** = es gibt ein Objekt, aber es sieht anders aus als der Text · **unklar**.
Priorität: **hoch** = Spieler steht vor dem Ding und sieht den Widerspruch sofort · **mittel** = sichtbar, aber ein Detail · **niedrig** = Kleinkram oder im Inneren eines geschlossenen Objekts.
