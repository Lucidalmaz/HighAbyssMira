Kein Pfad zeigt ins Leere.
- Wichtig: In `amt.js` stehen an vielen Stellen Kommentare „Rückfall: …; fehlendes Modell: …“. Im Code gibt es diesen Rückfall nicht. `amt_kit` liefert bei einem Ladefehler `null`, `amt_put` macht dann nichts: das Objekt fehlt dann spurlos (nur `console.warn`). Betroffen wären Nadeldrucker/Rollwagen, Funkgerät, Thermoskanne, Telefon, Leiter, Batterien, Kette, alle Stühle/Tische/Schränke. Die Hitboxen blieben in dem Fall stehen (also „nur Hitbox“).
