# Abgleich Text gegen Welt: Kapitel 3 (Nimmerheim, weiße Räume, Justin)

Geprüfte Module (`app/mods/`): kapitel3.js, lucy3.js, justin.js, neben3.js, weiss.js, traum.js, visionen.js, cleo.js, zayn.js, figuren.js.
Methode: alle Textstellen (`subtitle`, `say`, `toast`, `openNote`, `gedanke`, Lore, Interaktions-Labels) gelesen, jede behauptete sichtbare Sache gegen Mesh/Decal/Modell im Code gesucht. Eine reine `hidden`-Hitbox zählt nicht als sichtbares Objekt. Eingetragen sind nur belegte Lücken, Unsicheres ist als „unklar“ markiert. Es wurde kein Code verändert.

Legende „gefunden?“: ja / **nur Hitbox** / **nein** / **teilweise** / **unklar**.
Priorität: **hoch** = der Spieler sieht den Widerspruch sofort; **mittel** = fällt beim genauen Hinsehen auf; **niedrig** = Randdetail.

## C. Ladefehler-Risiken (Modell fehlt nur, wenn ein Ladefehler auftritt)

- kapitel3.js:301-315: Anni (`msFBX w_papierlaterne`), „Luke von hinten“ (`luke_erw`) und alle Nachbild-Figuren laufen in `try/catch` mit `console.warn`. Fällt `figuren_embody` oder `figuren_skc` aus, fehlen die Figuren lautlos (Nachbild 2009 zeigt dann nur Text). Gleiches gilt für das Zählbuch-Modell (`w_buch`, Rückfall: Kiste `zbook`).
- neben3.js:660 `kirchberg_figur` liefert `null`, wenn `lwo_neueFigur` fehlt (LWO nicht bereit): dann fehlen Gisela und Dina; `neben3_kueche` bricht bei `!F` ab, die Aufgabe `kb_naepfe` kann nicht abgeschlossen werden (Fortschrittsblocker bei Ladefehler).
- lucy3.js:468-471: Nachhall-Figuren der Unterschriften (`reuter`, `vegas`, `mama`, `hilde`); bei Fehler nur Ton/Untertitel ohne Gestalt (`useGhost` false). `lucy3_buildCar` hat einen Ersatz (feste Scheibenlage).
- weiss.js: Birken (`w_birke`), Grasbüschel (`wildgrass1`), Laterne (`lantern2`), Papierlaterne (`w_papierlaterne`) je in `try/catch`; bei Ausfall fehlen Birken/Kinder-Laternen bzw. die große Laterne (`S.lampion`), der Text bleibt.
