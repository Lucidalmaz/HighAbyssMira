# Abgleich Text gegen Welt: Kapitel 1 und Ort Lost Eyengless (Hauptstraße)

Geprüfte Module (app/mods): kapitel1, kapitel, albers, whiskey, post, strasse, kirchberg, nr4, beobachter, katzen, tausch, fotos, album, geheimnisse.

Methode: alle Textstellen (subtitle, say, toast, openNote, gedanke, Zettel-/Lore-Texte, Quest-Beschreibungen, Interaktions-Labels) gelesen. Jede konkrete sichtbare Behauptung wurde gegen die Bauanweisungen im Code (Modell, Mesh, Dekal, Sprite) geprüft. Reine Hitboxen (hidden-Material) zählen als "nur Hitbox". Die sieben Indizienfotos (fotos.js) und die Polaroids wurden zusätzlich als Bilddateien angesehen.

Statuswerte: nein = nirgends gebaut. nur Hitbox = Klickfläche ohne sichtbares Objekt. teilweise = Ersatzobjekt, das dem Text nur grob entspricht. unklar = nicht eindeutig prüfbar.
Koordinaten: Welt (x, z). Räume weit außerhalb (x ca. −1400, z ca. 1400) sind als Innenraum genannt. Y = Bodenhöhe der Häuser.

Ladefehler: Alle von diesen Modulen verwendeten Scan-Modelle (ms/*) samt Dateinamen liegen auf der Platte (per Skript gegen game/assets/ms geprüft, kein fehlendes Modell). Bewusst nicht vorhandene Assets sind im Code kommentiert (Kindersitz, Reiter und Bettler, Pfandflaschen). kirchberg_mod() liefert bei einem Ladefehler still null, dann würde das Objekt ohne Hinweis fehlen.

Priorität: hoch = Spieler sieht den Widerspruch sofort (Bild oder Objekt direkt neben dem Text, Kernszene Kapitel 1). mittel = fällt beim Hinsehen auf. niedrig = Randdetail.
